# packages/ui

Shared UI components used by `apps/dashboard` (and, where applicable,
`apps/chat-widget`'s own UI).

This is currently a **structure-only scaffold** (added during the apps/ +
packages/ + infra/ restructure). The actual shared components still live in
`apps/dashboard/src/shared/components/` and the widget-specific ones in
`apps/dashboard/src/widget/` — nothing has been extracted out of there yet.
